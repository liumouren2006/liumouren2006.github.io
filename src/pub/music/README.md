# 音乐播放器使用说明

播放器是右下角的悬浮按钮，展开后可以播放、暂停、切歌、拖动进度、调音量和查看播放列表。

## 添加歌曲

1. 把音频文件放进这个目录（`src/pub/music/`），例如 `song.mp3`。
2. 编辑 `playlist.js`，在 `window.MUSIC_PLAYLIST` 数组里加一行：

```js
{
  title: '歌名',
  artist: '作者',
  src: 'song.mp3',
}
```

`src` 相对于 `src/pub/music/` 解析；子目录写 `tracks/song.mp3`，外链写完整 URL。

推荐使用 `mp3`、`ogg`、`m4a` 或 `wav`。不同浏览器支持的格式略有差异，`mp3` 最稳。

## 示例曲目

`emerald-breeze.wav` 是为了演示播放器生成的一段环境音，可以直接删除，并同步删掉 `playlist.js` 里对应的条目。

## 说明

- 浏览器通常不允许网页自动播放声音，所以第一次需要手动点播放。
- 播放器会记住上次的曲目、进度、音量和面板状态，刷新或跳转文章页后会接着显示。
- 切歌、进度和音量只在当前浏览器里保存，不会上传到服务器。
